# @goodandready/dsh-goal

> **Плагин целеполагания и автономного выполнения задач (Goal Mode) для DeepSeek Harness**

`dsh-goal` внедряет в DeepSeek Harness автономный режим целеполагания с закреплённой верхней панелью (Sticky Top Banner), декомпозицией шагов на вехи (milestones), живым таймером и интерактивным управлением (пауза, продолжение, отмена, окно детального чеклиста).

---

## Возможности

- 🎯 **Закреплённая панель цели (Top Banner)**: компактная плашка над чатом в стиле нативного UI DSH:
  - Иконка мишени 🎯;
  - Лейбл «Текущая цель» и название активной задачи;
  - Живой секундомер выполнения (`• 2s`, `• 14s`, `• 2m 10s`);
  - Быстрые кнопки: 🗑 (сбросить/отменить), ⏸ / ▶ (пауза/возобновление), ⛶ (развернуть детали).
- ⛶ **Модальное окно чеклиста вех**: подробный список подзадач, прогресс-бар выполнения (0–100%) и лог шагов.
- 🤖 **Инструменты для модели**:
  - `goal_set_milestones` — разбиение цели на этапы;
  - `goal_update_progress` — фиксация выполнения очередного этапа;
  - `goal_finish` — завершение цели с итоговым резюме.
- 🛡️ **Safety Guardrails**: настраиваемый лимит шагов (maxIterations) для защиты от зацикливания.
- ⚙️ **Карточка настроек**: управление плагином во вкладке «Настройки → Плагины».
- 🌐 **Локализация**: полная поддержка русского и английского языков.

---

## Установка

```bash
dsh plugin add @goodandready/dsh-goal
```

Требуется ядро DeepSeek Harness **0.1.2-rc.1** или новее: клиентская половина не объявляет внешних клиентских модулей (`dsh.client.inject: []`), потому что в rc.1 `slots` / `locale` / `settingsScope` — встроенные службы ядра, а настройки плагина регистрируются schemastery-схемой.

## Настройки

Настройки живут в карточке плагина: **Настройки → Плагины → Настройки плагинов** («Цели и автономный режим (Goal Mode)»). Карточка читает живой снимок пространства настроек (пока пространство не в статусе `ready`, карточка не рисуется) и сохраняет только изменённые поля; неудачная запись не стирает введённые значения.

| Поле | Тип | По умолчанию | Назначение |
|---|---|---|---|
| `maxIterations` | число | `25` | Safety-лимит: максимум автономных итераций на цель |
| `autoDrive` | булево | `true` | Продолжать автономный цикл после каждого хода |
| `enableSound` | булево | `true` | Звуковой сигнал по завершении цели |

Пространство настроек: `dsh-goal`.

## Использование

1. Поставьте цель сообщением в чате:
   ```text
   /goal Исправить баг в аутентификации и добавить тесты
   ```
2. Или отправьте команду через REST API:
   ```bash
   curl -X POST http://localhost:3080/dsh-goal/action \
     -H "Content-Type: application/json" \
     -d '{"action":"start","title":"Привет"}'
   ```
3. Сверху появится панель с таймером и кнопками управления.
